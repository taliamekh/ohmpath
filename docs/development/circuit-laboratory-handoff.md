# Circuit laboratory handoff

This bounded addition provides two independently selected, fixed ngspice templates. It does not expand imported KiCad support or execute user-supplied SPICE text.

`ohmpath.circuits.laboratory.run_rc_transient(resistance_ohm=1000.0, capacitance_f=1e-6, supply_v=3.3, *, work_root: pathlib.Path) -> dict` generates a step-driven series-R/shunt-C transient. Parameters are finite and bounded (100–1,000,000 Ω; 1 nF–1 mF; 0.1–5 V). It returns at most 201 trace points, actual simulator and netlist SHA-256 hashes, simulator version, bounded logs/runtime, status/provenance, and an ideal `tau=RC` / 63.2% crossing comparison. A failed or unavailable simulator returns no trace.

`ohmpath.circuits.laboratory.run_diode_sweep(resistance_ohm=1000.0, maximum_supply_v=3.3, *, work_root: pathlib.Path) -> dict` runs a fixed 101-point, 0-to-maximum-voltage sweep of a generic educational silicon diode through a series resistor. The resistor is bounded from 100 Ω to 1 MΩ and the maximum source voltage from greater than zero through 5 V. The bundled model is `ohmpath.educational-shockley-silicon.v1`, using the ngspice parameters recorded in the result and fixture. Its parameters are illustrative defaults, not manufacturer-certified or fitted to a particular part. The result distinguishes simulator samples from a separate ideal Shockley comparison and reports the comparison's maximum relative current difference.

Both templates launch only the resolved ngspice executable with fixed `-b` and a generated netlist path, without a shell. Each run has a five-second child-process limit, 100 KB combined log limit, 250 KB numeric output limit, strict finite numeric parsing, exact expected point count, and fail-closed error status. `provenance` is `ngspice_actual` only for an executable-backed run; when ngspice is missing it is `none`. No mock or analytic data is substituted for simulator samples. Results describe simulation only, not physical measurement.

Verification completed from the repository root with `.venv\Scripts\python.exe -m pytest services\bench\tests\test_laboratory.py -q`: **11 passed**. The suite invoked the locally installed **ngspice-47** for both analyses. The RC result returned 201 points and passed the one-time-constant voltage/crossing checks; the diode result returned 101 points, was monotonic, and stayed within 0.7% maximum relative difference from the separately calculated Shockley reference at checked forward points. The same suite checked parameter bounds, missing-executable fail-closed behavior, malformed/oversized output, simulated fatal convergence output, and child timeout behavior. No package installation was needed. Tests that require actual ngspice will need ngspice 47 at the existing local path or `OHMPATH_NGSPICE` set to an installed executable.
